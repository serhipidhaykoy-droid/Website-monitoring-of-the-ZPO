Кабінет закладу освіти

Особистий простір для відповідальних осіб ЗПО

Захищений вхід для уповноважених осіб закладів професійної освіти Луганщини. Доступ до моніторингових форм закладу, історії звітів, статусу заявок та персоналізованих повідомлень від НМЦ ПТО.

Вхід до кабінету
