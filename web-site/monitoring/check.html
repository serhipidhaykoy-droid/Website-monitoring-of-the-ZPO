Що робити, якщо записи відсутні

  1. Якщо «Записи у Supabase» показує 0 для якоїсь форми — це означає, що ця форма не була подана з цього облікового запису. Перевірте, чи попередні дії на іншому комп'ютері були завершені кнопкою «Зберегти чернетку» або «Відправити».
  2. Якщо у localStorage є дані, але у Supabase 0 — означає, що Supabase save мовчки не спрацював. Відкрийте DevTools → Console на формі і подивіться чи є помилки.
  3. Якщо обліковий запис не прив'язано до закладу (червоний ⚠) — координатор НМЦ ПТО має оновити ваш user_metadata.institution_id у Supabase Auth.
